Privacy Policy

Last updated: 10 October 2026

AI Video Pipeline ("the app") is a private tool developed and operated by a single individual ("the operator") for the operator's own use. It connects only to the operator's own YouTube channel and TikTok account. This policy explains what data the app accesses, how it is used and stored, and how access can be revoked.

1. Data the app accesses

From Google / YouTube (YouTube API Services, with the operator's consent via Google sign-in; scopes youtube.upload and youtube.force-ssl):

  • the identifier, title and handle of the operator's YouTube channel;
  • the operator's own videos uploaded by the app: their identifiers, titles, descriptions, tags, privacy status and processing status;
  • view, like, comment and share statistics of these videos;
  • comments posted on these videos (comment text, author display name, time) and the operator's replies.

From TikTok (Login Kit and Content Posting API; scopes user.info.basic, video.upload, video.publish): the open ID, display name and username of the operator's TikTok account, the creator posting options, and the publishing status of the videos uploaded by the app.

The app does not access contacts, e-mail, files, location or any account other than the operator's own.

2. How the data is used

  • to upload and publish the operator's videos and keep their metadata up to date;
  • to show the operator the statistics of the published videos;
  • to let the operator read comments on these videos and reply to them. To help with replies, the text of a comment can be sent to the OpenAI API to generate a reply draft; the operator reviews every draft and decides whether it is posted. No other Google user data is sent to third parties.

The data is not sold, not used for advertising, and not used to train AI models. (Under OpenAI's API data policy, data sent through the API is not used for model training by default; OpenAI may retain it for a limited period for abuse monitoring.)

AI Video Pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Storage and security

  • The app and its database run on the operator's own computer at home (apart from the comment texts sent to the OpenAI API for reply drafts, see section 2).
  • OAuth refresh tokens are stored encrypted (AES-256-GCM); short-lived access tokens are kept only in memory.
  • The app is reachable only from the operator's home network and private VPN.

4. Retention, deletion and revoking access

  • Stored tokens are deleted when the operator disconnects the account in the app.
  • Statistics and comments are kept only as long as the operator needs them for the published videos and are deleted on request.
  • Google access can be revoked at any time on the Google security settings page; TikTok access in the TikTok app's settings (Security → apps and services permissions).

5. YouTube and Google

The app uses YouTube API Services. By using the app's YouTube features you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
